🛒 Walmart Products Search

MariaDB + Node.js RAG Demo - Search through 1,011 products

📡 Available API Endpoints

  • GET /api/products - All products (paginated)
  • GET /api/search?q=laptop - Search products
  • GET /api/generate-vector?q=text - Generate vector embedding
  • GET /api/semantic-search?q=text - 🔥 Semantic search with vectors
  • GET /api/recommend?q=text - 🤖 AI recommendations
  • GET /api/categories - Product categories
  • GET /api/brands - Product brands
  • GET /api/stats - Database statistics
  • GET /health - Health check
